# Documentation

- Keep the root README minimal and user-facing.
- Keep `agents/README.md` as an index only.
- Put detailed instructions in topic-specific files.
- Add new guidance to the most specific existing file.
- Create a new file only when the topic does not fit existing files.
- Keep new files small and focused.
- Avoid duplicating rules across files.
- Split files that become too large or mixed-purpose.
- Update `agents/README.md` whenever a new agent file is added.
- Keep documentation current with actual package scripts and folder paths.
