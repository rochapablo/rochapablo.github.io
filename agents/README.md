# Agent Documentation

This folder contains focused instructions for agents working on the static Pablo Rocha portfolio.

## Reading Order

1. `codegraph.md` - use CodeGraph and targeted search before broad exploration.
2. `cost-control.md` - keep context, commands, and reports small.
3. `profile-data.md` - protect all visible profile data values.
4. `layout.md` - preserve the accepted portfolio layout and visual direction.
5. `code-quality.md` - keep changes clean, DRY, focused, and behavior-preserving.
6. `javascript.md` - follow the current vanilla JS module structure.
7. `scss.md` - follow the current SCSS theme and partial structure.
8. `validation.md` - run only the smallest relevant validation.
9. `documentation.md` - keep project and agent documentation organized.

## Documentation Rule

Add new agent guidance to the most specific existing file. Create a new small file only when no existing topic fits, and link it here. Do not duplicate the same guidance across files.
