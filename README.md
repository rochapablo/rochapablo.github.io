# Pablo Rocha Landing Page

Minimal static personal landing page for Pablo Rocha.

## Requirements

- Node.js
- npm

## Setup

```bash
npm install
```

## Local Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Validation

```bash
npm run validate
```

```text
.

|-- src/

|   `-- tools/
|-- dist/

```
