# Code Quality

- Keep code clean, simple, and readable.
- Keep code DRY.
- Avoid duplicate logic, styles, strings, selectors, helpers, and render patterns.
- Reuse existing helpers, modules, styles, and scripts before creating new ones.
- Keep files small and focused.
- Preserve behavior unless the user explicitly requests a behavior change.
- Prefer small targeted changes over broad rewrites.
- Do not invent parallel implementations.
- Do not touch unrelated files.
- Keep the project static and GitHub Pages friendly.
- Do not change `Pablo Rocha` to another name.
